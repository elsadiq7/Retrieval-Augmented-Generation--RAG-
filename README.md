# RAG (Retrieval-Augmented Generation) Course

## Course Overview
This repository contains materials for [Retrieval-Augmented Generation with Large Language Models](https://www.coursera.org/learn/retrieval-augmented-generation-rag) course offered by DeepLearning.AI.

[Course Certification](https://www.coursera.org/account/accomplishments/verify/RVB25J4X7ABQ)

## Course Structure

### Module 1: Introduction to RAG Systems
- Basic Python refresher
- Introduction to LLM calls
- Simple augmented prompts
- Assignment: Building basic RAG components

### Module 2: Retriever Functions in RAG
- Vector embeddings fundamentals
- Retrieval metrics and evaluation
- Assignment: Implementing retriever functions

### Module 3: Vector Databases
- Introduction to Weaviate API
- Text chunking strategies
- Assignment: Building RAG systems with vector databases

### Module 4: RAG-based Chatbot Development
- LLM capabilities exploration
- Prompt engineering techniques
- Assignment: Developing a functional RAG-based chatbot

### Module 5: Advanced RAG Implementation
- System tracing and debugging
- Performance optimization
- Final implementation project



## Directory Structure
- `Module X/`: Contains materials for each module
  - `Assignment/`: Programming assignments
  - `Ungraded Lab/`: Practice exercises
  - `dataset/`: Required data files
  - `utils.py`: Utility functions
  - `flask_app.py`: Vector database server configuration

## Technologies Used
- Python
- Weaviate Vector Database
- LLM APIs
- Flask
- Jupyter Notebooks

## Prerequisites
- Python 3.8+
- Docker (for Weaviate)
- Basic understanding of machine learning concepts
- Familiarity with Python programming
